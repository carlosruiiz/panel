# 🏪 Panel de Comercio

> Sistema oficial de gestión de eventos comerciales de **Paragon**.
>
> Desarrollado para la **Facción de Comercio**.

---

## 📋 Funcionalidades

- ✅ Publicación de eventos por parte de los negocios.
- ✅ Inicio de sesión mediante nombre del negocio y contraseña.
- ✅ Gestión de eventos propios.
- ✅ Almacenamiento local mediante LocalStorage.
- ✅ Compatible con GitHub Pages.

---

# 🚀 Acceso

Accede al panel desde:

> https://carlosruiiz.github.io/panel/

Inicia sesión utilizando:

- **Nombre del negocio**
- **Contraseña** facilitada por la **Facción de Comercio**

---

# 📅 Publicar un evento

Una vez dentro del panel podrás:

- Crear nuevos eventos.
- Editar eventos existentes.
- Eliminar eventos finalizados.
- Consultar todos los eventos activos.

Los cambios se aplican automáticamente al tablón.

---

# ✏️ Recomendaciones

Antes de publicar un evento:

- Utiliza un título claro.
- Indica fecha y hora si corresponde.
- Explica brevemente en qué consiste.
- Revisa la información antes de guardarla.

---

# 🔒 Seguridad

La cuenta de tu negocio es de uso exclusivo del propietario y de las personas autorizadas.

No compartas la contraseña con terceros.

---

# 💾 Guardado

Toda la información se guarda automáticamente.

No es necesario pulsar ningún botón para guardar los cambios.

---

# ❓ Soporte

Si detectas algún error o necesitas ayuda con el panel, contacta con la **Facción de Comercio** mediante los canales oficiales del servidor.
